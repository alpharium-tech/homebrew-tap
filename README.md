# Alpharium Homebrew tap

```sh
brew install --cask alpharium-tech/tap/groupshelf
```

| Cask | App |
|---|---|
| `groupshelf` | [GroupShelf](https://group-shelf.com/) — groups windows from any app into browser-style tabs (macOS 15+) |

GroupShelf updates itself in-app; `brew upgrade --greedy` also works.
